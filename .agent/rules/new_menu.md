# Arkaya Website 页面架构优化版

基于最新页面架构草图，本版 `menu.md` 重新收敛为 7 个一级栏目：

1. `Home / 首页`
2. `Products`
3. `Solutions`
4. `Projects`
5. `How It Works`
6. `Resources`
7. `About / 关于我们`

整体原则：

- 首页不再堆过多业务解释，先完成品牌定位、客户分流和信任建立。
- 菜单从“卖货式分类”调整为“决策路径式架构”，优先服务开发商、设计师、建筑师等核心 B 端角色。
- 产品页承接能力展示，解决方案页承接不同角色需求，案例页承接信任，流程页承接转化。
- 所有页面都围绕一个核心价值表达：`设计 + 产品 + 交付`。

---

## 1. Home / 首页

首页是整个站点的总入口，目标不是讲全，而是快速让访客知道：

- 我们是谁
- 我们服务谁
- 我们怎么做
- 为什么值得信任
- 下一步该点哪里

### 1.1 Hero 大 banner 板块

建议首屏结构：

- 主标题：一句话定位 Arkaya
- 副标题：明确讲清楚 `设计 + 产品 + 交付`
- 主 CTA：`预约咨询`
- 次 CTA：`上传户型图`

建议文案方向：

- `Luxury Interiors, Delivered End to End.`
- `From Design to Product to Delivery for High-End Residential Projects.`
- 中文表达可对应：`为高端住宅项目提供从设计到产品到交付的一站式落地服务。`

### 1.2 三类客户入口

首页首屏后直接做人群分流，避免所有访客看同一套话术。

- `For Homeowners`
- `For Architects & Designers`
- `For Builders & Developers`

每个入口都跳转到对应解决方案页，入口卡片内只讲一个核心利益点。

### 1.3 核心价值 / 信任传递

这部分不是品牌自夸，而是降低客户顾虑，建议做成 4 条价值卡片：

- 一站式落地，帮客户少操很多心
- 更确定，不再为跨境交付担心
- 更高性价比，不是便宜，而是花得值
- 更专业的协同能力，复杂项目也能推进

### 1.4 How Arkaya Works 摘要

首页中段放一版简化流程，帮助访客快速理解合作方式：

1. 咨询
2. 方案
3. 报价
4. 生产
5. 配送安装
6. 售后质保

这部分只做摘要，每一步可跳转至 `How It Works` 详情页。

### 1.5 精选案例

建议展示 3-6 个代表性项目卡片，重点不是数量，而是覆盖不同项目类型：

- 豪宅整装
- 样板房 / staging
- 设计师合作项目
- Builder / Developer 项目

每张卡片至少包含：

- 项目名称 / 地区
- 项目类型
- 服务范围
- 一句结果导向描述

### 1.6 信任体系

用于回答“你们靠谱么”。

建议包含以下信任模块：

- 质保
- 延期保障
- 第三方监督接口
- 项目管理机制
- 本地安装 / 交付网络

### 1.7 客户评价 / 合作伙伴

这一屏建议组合展示：

- testimonial 客户评价
- partner / client logo
- 媒体背书或行业引用

## 2. Products

产品页不只是罗列 SKU，而是展示 Arkaya 能承接的产品范围和风格能力。

### 2.1 家具和软装

作为核心展示品类，建议按空间和风格双维度组织：

- 客厅
- 餐厅
- 卧室
- 户外
- 软装配饰

参考网站方向：

- `https://www.arhaus.com/`
- `https://www.cb2.com/`
- `https://polyandbark.com/`
- `https://zgallerie.com/`
- `https://www.westelm.com/`

### 2.2 定制门窗

建议拆成两个主方向：

- 法式风格
- 美式风格

重点展示：

- 外观语言
- 常见开启方式
- 常用材料与工艺
- 可适配项目场景

### 2.3 楼梯

建议以“结构 + 风格 + 材质”三个维度组织内容，例如：

- 现代悬浮楼梯
- 欧式雕花楼梯
- 木作 + 金属混搭

### 2.4 橱柜定制

重点强调：

- 全屋系统收纳
- 厨房 / 衣帽间 / 卫浴柜体能力
- 高端住宅项目的统一风格控制

### 2.5 入户门、栅栏、车库门

这部分更偏外立面与住宅门庭形象，应作为高客单配套能力展示。

建议内容重点：

- 风格统一性
- 材料耐候性
- 与建筑立面语言协调

## 3. Solutions

`Solutions` 是面向不同客户角色的解决方案入口，负责把“同一家公司”翻译成“不同角色都能听懂的价值表达”。

### 3.1 Solutions Overview / 解决方案总览

总览页的目标：

- 讲清 Arkaya 的服务边界
- 讲清不同角色各自得到什么
- 引导进入细分角色页

### 3.2 For Homeowners / 面向业主

重点诉求：

- 省心
- 效果统一
- 从设计到落地一体化

适合强调：

- 风格提案
- 主材 + 家具 + 软装整合
- 预算控制
- 安装交付协同

### 3.3 For Architects & Designers / 面向设计师与建筑师

重点诉求：

- 协作效率
- 设计还原度
- 材料与产品资源整合

适合强调：

- 深化配合
- 样品与材质支持
- 产品选型支持
- 项目制执行

### 3.4 For Builders & Developers / 面向建商与开发商

重点诉求：

- 控预算
- 控进度
- 控风险
- 提升交付完成度

适合强调：

- 批量项目协同
- 从硬装到软装的一站式采购
- 交期管理
- 供应链和安装能力

### 3.5 Product & Package / 产品包

这里可以把解决方案进一步产品化，方便报价与销售转化。

建议拆分：

- `Furniture Package`
- `Interior Finish Package`
- `Turnkey Residential Package`
- `Showhome / Staging Package`

## 4. Projects

案例是成交前最重要的信任资产之一，建议单独成立案例中心，而不是零散分布在各页。

### 4.1 Case Study Hub / 案例总览页

支持按以下维度筛选：

- 项目类型
- 服务范围
- 风格
- 地区
- 客户类型

### 4.2 Case Detail / 案例详情页

每个案例建议统一结构：

1. 项目背景
2. 客户需求
3. 我们提供的服务范围
4. 方案亮点
5. 交付结果
6. 图片 / 对比 / 客户反馈

建议案例详情避免只放美图，要体现项目执行能力与结果导向。

---

## 5. How It Works

这个栏目用于回答客户最关心的问题：`你们到底怎么合作，靠不靠谱，项目怎么推进？`

### 5.1 Our Process / 服务流程

做一张从咨询到售后的完整流程图，突出每阶段输出内容。

建议流程：

1. 需求沟通
2. 初步方案
3. 深化与报价
4. 下单生产
5. 出货与运输
6. 安装与交付
7. 售后与质保

### 5.2 Design to Delivery / 从设计到交付

这一页重点讲“我们不只是做设计图，而是负责落地”。

建议说明：

- 设计阶段输出什么
- 采购阶段如何衔接
- 交付阶段如何协同
- 如何减少返工和信息断层

### 5.3 Timeline & Milestones / 时间线与节点

建议把项目推进拆成关键节点，让客户感知确定性：

- 需求确认
- 方案确认
- 清单确认
- 下单生产
- 质检验货
- 国际运输
- 本地安装
- 项目验收

### 5.4 Pricing Approach / 报价逻辑

这页很重要，目的是建立价格信任，不是直接给死价。

建议说明：

- 报价由哪些部分构成
- 什么因素会影响价格
- 标准品与定制品的差异
- 为什么“做得好”需要合理的价格表达

## 9. 这一版架构的优化重点

相较旧版，这一版做了 5 个关键优化：

1. 从“大而全的战略文档”改成“可直接用于网站搭建的信息架构文档”。
2. 从复杂 B2B 术语堆叠，改成用户更容易理解的导航逻辑。
3. 首页承担品牌、分流、信任、转化四个任务，不再过载。
4. `Solutions` 和 `Projects` 被明确拉开，一个讲角色方案，一个讲真实案例。
5. `How It Works` 被单独强化，帮助高客单客户建立流程信任。

## 10. 下一步建议

如果继续往下推进，建议按这个顺序展开：

1. 先把 `Home` 做成完整页面 wireframe。
2. 再补 `Solutions` 三个角色页的页面文案框架。
3. 然后整理 `Projects` 的案例卡片模板和详情页模板。
