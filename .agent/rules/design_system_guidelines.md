# 奢华建材家居 B2B 平台设计规范指南 (Design System & Guidelines)

针对目标市场（**美国 $3M-$10M 豪宅**）和目标客户群（**B2B 开发商、建筑商、专业设计师**），结合 RH、Porcelanosa、Poliform 等国际顶级品牌的官网视觉基因，我们的平台应恪守 **"Quiet Luxury" (老钱风/静奢风)** 与 **"Architectural Minimalism" (建筑极简主义)** 的设计哲学。

总体原则是：**用极简、克制的黑白灰框架，去承托和放大我们产品库中（硬装建材、顶级软装）材质本身的肌理、光影和设计感。网站本身要“退后”，让产品“上前”。**

---

## 💡 核心视觉氛围 (Visual Atmosphere)

1. **绝对的主色调：黑、白、灰（高对比与低饱和）**
    *   **背景色 (Background)**：以纯白 (`#FFFFFF`) 或极浅的冷灰 (`#F5F5F7` / `#FAFAFA`) 为主，营造画廊般的留白（White Space）。部分沉浸式展示区（如全案案例、深色石材）可切换为纯黑 (`#000000`) 或深邃炭灰 (`#1A1A1A`) 进行视觉反差。
    *   **文本色 (Typography Color)**：采用深灰 (`#333333` 或 `#111111`) 而非刺眼的纯黑，提升奢华感与阅读舒适度。辅助文本使用中灰 (`#7A7A7A`)。
    *   **品牌高亮/点缀色 (Accent Color)**：**尽量避免使用任何鲜艳的饱和色（如亮红、亮蓝等互联网常见色）。** 如果必须有强调色，建议选用非常低调的金属色（如香槟金、拉丝黄铜）或自然的木质暖棕色，且仅在极少数交互反馈（如Hover、精细分割线）中使用。

2. **海量留白 (Negative Space is Luxury)**
    *   留白是高级感最重要的来源。无论是在产品列表还是内容区块之间，都要保证极大的间距。不要试图在一个屏幕内塞满所有的信息。奢侈品牌从来不“叫卖”。

3. **大图与材质质感 (Immersive Imagery)**
    *   产品图和场景图必须是最高清晰度的。图片不仅要展现整体设计，**更要特写展示材质的肌理、光泽和工艺细节（如大理石纹理、实木年轮、黄铜拉丝等）**。

## ✏️ 字体选择指南 (Typography Guidelines)

针对 Next.js 项目，建议直接使用 `next/font/google` 引入以下无极粗细变体（Variable Fonts）的免费且顶级的 Google 字体：

### 1. 标题字体 (Headings) - **优雅、克制、带有建筑感**
*   **首选 (无衬线) -  `Outfit`**
    *   *特点*：极其干净、几何感强、现代主义。适合绝大多数的主界面和信息传达。虽然 `Inter` 很常用，但它能完美融入黑白极简框架，不抢戏。`Outfit` 则更具现代几何建筑气息。
*   **备选 (衬线体 - 营造老钱风氛围) - `Playfair Display` 或 `Cinzel`**
    *   *说明*：如果希望在某些特定的品牌故事页面、大屏主视觉（Hero Section）中增加一点古典或极度奢华的品牌气质，可以非常谨慎地使用衬线体作为巨大号的标题。其余界面一律回归无衬线。

### 2. 正文/据字体 (Body & Data) - **极致的易读性**
*   **首选 - ` 或 `Roboto Mono` (针对规格参数)**
    *   *说明*：长文本使用轻量级（Light/Regular）的 `Inter`。对于开发商非常看重的**产品规格、尺寸参数、CAD图纸数据等**，强烈建议使用等宽字体（如 `Roboto Mono` ），这能传达出一种极其精确、专业、工业级的 B2B 信赖感。

## 💻 推荐的 Next.js 前端 UI 库与技术栈

为了兼顾“极致定制化的奢华视觉”和“B2B后台强大的数据交互能力”，不建议使用默认样式感太强、看起来“太像普通后台”的 UI 库（如默认的 Ant Design 或 MUI）。

### 1. 核心 Styling 方案：Tailwind CSS (必选)
*   **原因**：Tailwind CSS 的原子化特性允许开发者不受任何预设 UI 组件的束缚，能 100% 像素级地还原设计师的黑白极简界面和极细致的间距（Whitespace）控制。极其适合实现“反常规组件”的定制化高端设计。



### 4. 动效库 (Animation) - **Frame Motion**
*   **说明**：奢华感离不开微动效。但是必须“极其克制”。禁止使用弹跳、猛烈划入等夸张动效。使用 **Framer Motion** 实现缓慢（duration 较长，通常在 0.6s-1.2s 左右）、丝滑的**渐隐渐现 (Fade-in)**、背景视差 (Parallax) 或图片缓慢拉近 (Ken Burns effect)。

## 📐 B2B 开发商端业务的专属交互设计 (UX for Developers)

B 端客户（开发商）和 C 端买家不同，他们不是来“逛”的，而是来**干活和决策**的。设计必须兼顾“奢华第一印象”与“极度高效的工具属性”。

1. **Specs 第一性 (技术参数优先)**
    *   不要只有“好看的场景图”。每个建材/家具详情页，必须用极度专业的工业排版（类似蓝图的设计语言）展示长宽高、材质成分、防火等级、环保认证、安装要求的表格。
2. **"Tear Sheet" & 资料包一键下载**
    *   每个产品必须有一个设计极其精美的 `Download Tear Sheet (产品简报)` 按钮（PDF格式），方便设计师和开发商直接塞进他们的提案(Pitch Deck)里。同时支持 CAD/3D 模型的下载。
3. **Project Management (项目收藏夹/BOM清单化)**
    *   放弃 C 端传统的“购物车 (Cart)”概念。B 端需要的是 **“项目清单 (Projects/Folders)”**。他们可能会同时建立 "Miami Villa Project A" 和 "NY Penthouse B" 的清单，并在里面分类管理硬装、软装预算及产品件数。
4. **一键 "Request Quote" (询价系统)**
    *   在极简界面中，核心的转化动作是“加入项目单”和“索取批量报价 (Request a Quote)”，流程要像发送一封极其私密的专属邮件一样优雅，而不是弹出一个花哨的促销弹窗。
